# 【学雷锋 在行动】第一医学中心：岗位学雷锋 争当新先锋

> 更新时间：2026-09-16 (UTC+8)

**雷锋宣传月**　　３月５日是第59个“学雷锋纪念日”，雷锋精神薪火相传，并不断赋予新的时代内涵。为传承雷锋精神，解放军总医院第一医学中心积极响应号召，各医学部、科室结合岗位实际组织开展了各具特色的学雷锋系列活动，以实际行动赓续红色血脉，展示新时代人民军医的风采。

****
**学习雷锋好榜样****神经外科医学部**　　神经外科医学部重症监护科团支部精心部署，本着把学雷锋活动切实落实到临床一线工作中的要求，创新开展了疫情防控下的学雷锋、树新风的“线上送健康”模式，关爱脑瘫弃婴，化身“天使”雷锋，对北京市儿童福利院的护理人员进行了护理知识的培训。冀蓁护士长前期了解福利院护理人员的护理需求，带领护理组对患儿约束、坠床预防、心肺复苏、胃管置入等常用护理知识进行了线上讲解和培训，认真温情的授课，充分体现了军队护理人员的社会责任感，传承新时代雷锋精神。

**学雷锋**
**消化内科医学部**
　　消化内科医学部立足本职岗位，积极开展学雷锋系列活动。利用团支部组织医护人员在门诊5层消化内镜中心开展义诊，严格落实疫情防控要求，佩戴口罩、一米距离、有序排队，为门诊就诊患者及家属进行消化系统疾病健康咨询，指导如何做好胃肠镜检查前的准备，免费测量血压、发放一次性口服泻药杯和内容丰富的健康宣传小册子，并对如何正确佩戴口罩及七步洗手法进行了演示。医学部柴宁莉副主任，各病区护士长及志愿者耐心、细心、认真、专业的服务解答受到前来就诊的患者及家属的称赞。

**神经内科医学部**
　　神经内科医学部发扬“党建带团建、团建促党建“的优良传统，把学雷锋活动同主题教育、党史学习教育结合，进行了微党课、微演讲活动，医学部于生元主任、谷洋光书记和团总支王君主任参加此次活动，每病区派一名团员为代表以新时代是否还需要雷锋精神为题并结合自身岗位进行发言。全体医务人员表示，将不忘初心、践行使命，像雷锋那样奋发向上、勇于担当、锐意进取，当好新时代人民军医，让雷锋精神代代相传。

**学习雷锋先锋岗**　　常态化疫情防控下，急诊医学科、病案管理科、住院管理科、病理科等多个科室设置了“学习雷锋先锋岗”，耐心细致地为患者办理业务；负责咨询和引导的同志，严格按照疫情防控要求为患者测量体温并做好流调筛查，通过服务交流增进了医患之间的感情，用实际行动弘扬雷锋可贵的精神，受到了部队官兵及广大患者的一致好评。 
 
 
 

 
 
 
 **暖心服务**
　　第一医学中心重症医学科开展“学雷锋互助行动”系列活动，进行线上宣教、发放手卫生步骤手册和正确佩戴口罩方法手册并现场示范；派驻心血管内科在组织义诊活动的同时，还自编弹力带康复操，护士们与前来义诊的患者家属共同跳起，成为最美的风景线。派驻骨科、派驻心脏大血管外科、胸外科等科室立足自身岗位，开展了测血糖、血压、健康咨询等学雷锋暖心活动，向群众宣传养生健康常识，提高群众的自我保健意识，让每一位患者享受到优质医疗服务。

**肿瘤中心**　　肿瘤中心的肿瘤内科、放射治疗科等科室结合工作实际，通过知识讲座和义诊活动等形式开展了学雷锋活动，各个患者及家属可以根据自己所需求的问题进行询问，每位医生、技师、护士尽职尽责，活动受到患者及家属的好评。
**疼痛科**
　　疼痛科冯泽国主任带领科室医生远程科普宣讲，主要针对群众日常生活中疼痛，进行了详细的讲解。唐果护士长在活动现场宣教疼痛方面的相关知识，并对癌痛患者进行情绪疏导；孙惠主管护师、张燕护士、王蕾护士现场为大家免费量血压、测血糖，受到了患者、家属及本院人员的一致好评。

　　第一医学中心将继续立足本职，以实际行动擦亮雷锋精神坐标，营造向上向善的良好氛围，展示新时代战略卫勤力量排头兵的风采。
